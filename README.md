Исследовательский программно-аппаратный комплекс для ранней инструментальной индикации признаков водного и осмотического дефицита растений защищенного грунта.

Система сопоставляет температурный отклик листовой пластинки (косвенный индикатор транспирационного охлаждения через портативную ИК-термографию) и спектральные характеристики отражения полога (активный двухволновой NoIR-спектрофотометрический тракт 660 / 850 нм) в светоизолированном боксе.

В пилотной модельной серии на горохе (*Pisum sativum*, сорт «Альфа», 11 суток) наблюдалось повышение температуры листа на 1.7–2.5 °C за 36–48 часов до наступления визуальной потери тургора, в то время как расчетный инструментальный индекс $NDVI_{\text{instr}}$ в этот период сохранял стабильные значения. Воспроизводимость эффекта и оценка применимости метода в условиях рандомизированного блочного дизайна проверяются во второй серии на огурце (*Cucumis sativus*, Волна 2).

## 1. Актуальность, цель, гипотеза и задачи исследования

### Проблема и научное обоснование
1. **Латентная фаза водного дефицита и инертность спектральных индексов:** В закрытых агробиотехнологических системах (сити-фермы, фитотроны) орошение традиционно назначается либо по жесткому таймеру, либо реактивно — при видимой потере тургора листьев. К моменту макроскопического увядания в тканях развиваются функциональные нарушения (снижение эффективности фотосистемы II, падение ассимиляции $\text{CO}_2$), снижающие итоговую продуктивность. Оптические спектральные индексы (включая $NDVI$) на ранних стадиях дегидратации малочувствительны, поскольку пул хлорофилла в мезофилле листа сохраняет оптическую плотность в первые сутки после прекращения полива.
2. **Ограниченность контактных датчиков почвы:** При засолении субстрата или осмотическом шоке физическая влажность грунта может оставаться высокой ($>75\%$), однако из-за снижения почвенного водного потенциала растение испытывает физиологическую засуху. Контактные датчики влажности почвы в этом сценарии рапортуют о норме, маскируя стресс корневой системы.
3. **Биофизический базис (модель Идсо–Джексона):** Первичным гидропассивным и гормональным ответом растения на дефицит влаги является защитное смыкание устьичных щелей. Прекращение транспирационного расхода воды неизбежно влечет повышение температуры листовой пластинки ($\Delta T = T_{\text{leaf}} - T_{\text{ambient}}$) за счет прекращения испарительного охлаждения.

### Научная гипотеза
> **Рабочая гипотеза:** Термометрический сигнал смыкания устьиц ($\Delta T \ge +0.8^\circ\text{C}$ относительно фона) опережает спектральный отклик деградации хлорофилла (инструментальный спад $NDVI_{\text{instr}}$) на десятки часов, образуя диагностическое «окно упреждения», достаточное для превентивного полива и предотвращения необратимых потерь биомассы.

### Цель и задачи
**Цель работы:** Разработка, инструментальная калибровка и экспериментальная проверка аппаратно-программного комплекса двухволновой активной спектрофотометрии и термографии для ранней индикации функционального водного дефицита растений в защищенном грунте.

**Задачи:**
1. Спроектировать и изготовить светоизолированный фотометрический бокс с активным импульсным осветителем (660 / 850 нм), NoIR-сенсором и внешней термографической верификацией (UNI-T UTi120S).
2. Реализовать программный стек (FastAPI, OpenCV, вычитание темнового фона, балансировка каналов по PTFE-эталону, оптическое считывание телеметрии через OCR).
3. Провести пилотную 11-суточную модельную серию на горохе (*Pisum sativum*, 5 кассетных когорт, $n=45$) с цитологической верификацией устьиц лаковыми репликами и деструктивным учетом сырой биомассы.
4. Разработать протокол валидационной серии на культуре огурца (*Cucumis sativus*, Волна 2) с переходом на индивидуальные калиброванные сосуды (85.0 г), обобщенный рандомизированный блочный дизайн (GRCBD по Доспехову) и лизиметрический контроль непродуктивного испарения почвы $X0$ (FAO-56).

## 2. Аппаратно-оптический комплекс

### Конструкция фотометрического бокса
* **Корпус:** Изготовлен методом лазерного раскроя из шлифованной березовой фанеры ФК толщиной 4.0 мм на станке с ЧПУ Acmer S1 Pro (рабочее поле $380 \times 370$ мм).
* **Геометрия:** Габариты $210 \times 210 \times 305$ мм (полезная внутренняя высота 297 мм, внутренний просвет $202 \times 202$ мм). Соединения типа шип-паз с шагом 27–30 мм без паразитных зазоров.
* **Светоизоляция:** Внутренние поверхности покрыты матовым светопоглощающим составом. Накладной быстросъемный фасад фиксируется на неодимовых магнитах N52 через 3D-печатные угловые кронштейны. Чертежи доступны в каталоге [`hardware/laser_cutting/`](hardware/laser_cutting/).

### Спецификация оптики и датчиков
* **Спектральная камера NoIR:** 8-мегапиксельный сенсор Sony IMX179 (USB V4L2) со специализированным M12-объективом без ИК-отсекающего фильтра (спектральное окно 400–1000 нм, $f = 3.6$ мм, дистанция визирования 280 мм).
* **Активная подсветка:** Светодиодные излучатели 3W с длинами волн $\lambda_1 = 660$ нм (Deep Red, пик поглощения хлорофилла *a/b*) и $\lambda_2 = 850$ нм (NIR, плато отражения клеточной структуры мезофилла) на алюминиевых радиаторах с раздельным релейным управлением.
* **Тепловизионный канал:** Портативный микроболометр UNI-T UTi120S ($120 \times 90$ пикселей, спектральный диапазон 8–14 мкм, чувствительность $\text{NETD} < 60$ мК, рабочий коэффициент эмиссии $\varepsilon = 0.98$).
* **Микроклиматическая телеметрия:**
  * Зонд зоны постоянной вегетации (Xiaomi BLE / Sensirion SHT30): фоновые $T_{\text{ambient}}$, $RH_{\text{ambient}}$ и дефицит упругости пара ($VPD$);
  * Внутренний зонд бокса: Sensirion SHT30 (шина I2C-0, адрес `0x44`) на шлейфе у уровня полога;
  * Аналоговый почвенный сенсор: емкостной датчик v1.2, подключенный к 16-битному АЦП ADS1115 (дискретность 0.125 мВ/LSB).
* **Вычислительный узел:** Одноплатный компьютер Orange Pi 4 Pro V1.3.2 (Armbian Linux 6.1, оверлей `sun60i-a733-i2c0.dtbo`). Электроника вынесена в герметичный распределительный отсек для защиты от влаги и исключения паразитной засветки.

```
 [Образец в фотометрическом боксе]
         |
         +---> [Активный 3-фазный стробоскопический осветитель]
         |        |-- Фаза 1: Фоновая освещенность (L_amb, подсветка выключена)
         |        |-- Фаза 2: Реле Ch1 ВКЛ -> Импульс 660 нм (Deep Red) -> Экспозиция L_red -> Реле ВЫКЛ
         |        |   [Пауза 0.20 с для стабилизации экспозиции и питания]
         |        +-- Фаза 3: Реле Ch2 ВКЛ -> Импульс 850 нм (NIR) -> Экспозиция L_nir -> Реле ВЫКЛ
         |
         +---> [NoIR-камера Sony IMX179 8MP V4L2 1600x1200]
         |        +-- Радиометрический расчет NDVI с вычитанием темнового фона и балансом PTFE:
         |            R_diff = max(0, L_red - L_amb),  NIR_diff = max(0, L_nir - L_amb)
         |            NDVI_instr = (k_bal * NIR_diff - R_diff) / (k_bal * NIR_diff + R_diff)
         |
         +---> [Микроболометрический тепловизор UNI-T UTi120S] (NETD < 0.06 °C, e = 0.98)
         |        +-- Оптическое распознавание OCR дисплея: T_leaf и T_air -> расчет Delta_T и CWSI
         |
         +---> [Шина I2C-0: Sensirion SHT30 (0x44) + 16-бит АЦП ADS1115 (0x48)]
         |
         +---> [Беспроводной канал BLE 2.4 ГГц: Xiaomi Mijia в стационарной зоне вегетации]
         |
         +---> [Операторская веб-станция FastAPI / REST API / SQLite / CSV]
```

## 3. Программная архитектура и алгоритмы

Весь программный стек комплекса разработан на языке Python (версии 3.9–3.12) с модульной микросервисной архитектурой:

1. **Серверная станция оператора (`web_station.py`):**
   * Реализована на фреймворке **FastAPI** с асинхронным ядром;
   * Встроенный менеджер сессий экспериментов (`ExperimentManager`) с полной изоляцией каталогов данных (`data/experiments/<exp_id>/`);
   * Автономный режим точки доступа: Orange Pi автоматически поднимает защищенную Wi-Fi сеть `PlantStation` (`192.168.4.1/24`, mDNS `http://orangepi4pro.local:8000`) для управления с планшета или смартфона без внешнего интернета.

2. **Радиометрическая калибровка и статус инструментального индекса $NDVI_{\text{instr}}$ ($k_{\text{bal}} = 4.070$):**
   * **Спектральная специфика NoIR-матрицы:** Органические интерференционные светофильтры Байера бытовых CMOS-сенсоров (Sony IMX179) обладают паразитным пропусканием в диапазоне 750–1000 нм во всех субпикселях.
   * **Калибровка по PTFE-эталону:** Для нормировки спектральной чувствительности каналов использован диффузный отражатель из химически чистого политетрафторэтилена (PTFE, коэффициент отражения $\rho \approx 98.5\%$ в диапазоне 400–1000 нм, аналог Spectralon®). Коэффициент балансировки экспозиции:

$$
k_{\text{bal}} = \frac{DN_{660}^{\text{white}}}{DN_{850}^{\text{white}}} = \frac{195.2}{48.0} \approx 4.070
$$

   * **Формула инструментального вегетационного индекса с темновой компенсацией:**

$$
NDVI_{\text{instr}} = \frac{k_{\text{bal}} \cdot NIR_{\text{diff}} - R_{\text{diff}}}{k_{\text{bal}} \cdot NIR_{\text{diff}} + R_{\text{diff}} + 10^{-6}}
$$

     где $R_{\text{diff}} = \max(0, L_{\text{red}} - L_{\text{amb}})$, $NIR_{\text{diff}} = \max(0, L_{\text{nir}} - L_{\text{amb}})$. Формула обеспечивает калибровочное равенство $NDVI_{\text{instr}} \equiv 0.000$ на спектрально-нейтральной мишени PTFE.
   * **Разграничение со спутниковым/полевым NDVI:** $NDVI_{\text{instr}}$ является **узкополосным аппаратно-зависимым относительным индексом конкретной установки** (активное светодиодное квазимонохроматическое зондирование $660/850$ нм в замкнутом боксе при фиксированном угле подсветки). Он предназначен для высокочувствительного внутрисерийного мониторинга кинетики хлорофилльного поглощения конкретной выборки, но не подлежит прямому сопоставлению со спутниковыми индексами дистанционного зондирования Земли (Sentinel-2, Landsat) без проведения специализированной кросс-калибровки передаточной функции.

3. **Компьютерное зрение и фенотипирование полога (OpenCV):**
   * Автоматическая детекция фидуциальных меток ArUco (`DICT_4X4_50`) на кассетах: сопоставление ID когорты и масштабирование пикселей в сантиметры ($k_{\text{scale}} = 2.25 / A_{\text{px}}$);
   * Сегментация проективной площади листового полога (Projected Leaf Area, PLA) по комбинированной маске ($NDVI > 0.22$, $NIR_{\text{diff}} > 15$) с покассетным и поячеечным (C1–C9) разбиением.

4. **Оптическое считывание телеметрии тепловизора (OCR):**
   * Модуль субпиксельного распознавания экрана прибора UNI-T UTi120S на базе **Tesseract OCR** с предварительной бинаризацией и фильтрацией области центрального курсора ($T_{\text{leaf}}$) и референтной температуры среды ($T_{\text{air}}$).

5. **Модуль биометрии и математического анализа:**
   * Расчет индекса водного стресса покрова (Crop Water Stress Index, CWSI) по эмпирической модели Идсо:

$$
\text{CWSI}_{\text{instr}} = \frac{\Delta T - \Delta T_{\text{wet}}}{\Delta T_{\text{dry}} - \Delta T_{\text{wet}}} = \frac{\Delta T - 0.24 + 1.20 \cdot VPD}{1.26 + 1.20 \cdot VPD}
$$

     *(подробный протокол вывода регрессии см. в [`CALIBRATION.md`](CALIBRATION.md))*;
   * Двухфакторный дисперсионный анализ (**Two-Way ANOVA по Доспехову**) с апостериорным тестом Тьюки (HSD) для блочных экспериментов.

## 4. Экспериментальные исследования и результаты

### Серия 1: Пилотный 11-суточный мониторинг на горохе (*Pisum sativum*, сорт «Альфа»)
* **Дизайн выборки:** Синхронная посадка 5 кассетных когорт по 9 растений в ячейках C1–C9 ($n = 45$ растений):
  * К1: Постоянный поливной контроль (100% ПВ);
  * К2: Осмотический стресс (100 мМ NaCl в изолированном лотке);
  * К3: Терминальная засуха (полное прекращение полива);
  * К4: Превентивная регидратация (полив строго по термическому алерту $\Delta T \ge +0.8^\circ\text{C}$);
  * К5: Реактивное реагирование (полив при видимой макроскопической потере тургора).
* **Организация влагометрии субстрата в Серии 1:** Непрерывный инструментальный мониторинг влажности емкостными датчиками почвы через 16-битный АЦП ADS1115 осуществлялся в реперных кассетах К1 (Контроль), К2 (Осмос) и К3 (Засуха). В когортах превентивного и реактивного полива (К4 и К5) мониторинг динамики влагообеспеченности велся неинвазивным весовым методом (ежедневным взвешиванием всей кассеты на весах), что позволило исключить травмирование корневой системы контактными зондами перед точечным поливом.
* **Статус выборки (Hurlbert, 1984):** Поскольку фактор орошения задавался на уровне всей кассеты, кассета является экспериментальной единицей ($N = 1$), а ячейки C1–C9 — субповторностями (*subsamples*). Контрольное анатомическое вскрытие кассеты (`day11_root_isolation_proof.jpg`) подтвердило отсутствие переплетения корней между ячейками, исключив межрастениевую трофическую конкуренцию.

#### Ключевые результаты Серии 1 и разграничение уровней доказательности:

Для обеспечения академической строгости результаты пилотной серии разделены по **шкале уровней научной доказательности**:

* **Уровень 1 (Аппаратно-инструментальный — Доказано):**  
  Оптико-электронный тракт комплекса обеспечивает стабильное вычитание темнового фона и расчет $NDVI_{\text{instr}}$ без дрейфа нуля на мишени PTFE. Контактная сверка микроболометра UTi120S с поверенной термопарой типа K (мультиметр BSIDE ZT102) на живом листе показала расхождение всего $0.1^\circ\text{C}$ ($23.1^\circ\text{C}$ vs $23.0^\circ\text{C}$ при $\varepsilon = 0.98$).
* **Уровень 2 (Физиологический отклик — Доказано натурно):**  
  Светопольная микроскопия лаковых реплик эпидермиса по Молотилову (WF16×, объектив 40×, суммарное увеличение до 640×) подтвердила биологический субстрат температурного сигнала:
  * Контроль (К1): **85.7%** открытых устьиц (апертура 6–8 мкм, активная транспирация, $\Delta T = -1.6^\circ\text{C}$);
  * Терминальная засуха (К3): **7.1%** открытых устьиц (сомкнутые щели 0–1 мкм, плазмолиз замыкающих клеток, $\Delta T = +0.9^\circ\text{C}$);
  * Осмотический стресс (К2): **13.6%** открытых устьиц (физиологическая окклюзия при избыточной влажности субстрата $>80\%$, $\Delta T = +1.0^\circ\text{C}$).
* **Уровень 3 (Временная асинхрония сигналов — Наблюдение данной серии):**  
  В условиях 11-суточного опыта на горохе устьичный температурный сигнал дефицита влаги ($\Delta T = +1.7\dots+2.5^\circ\text{C}$ при падении влажности почвы до $14–18\%$) зафиксирован на 6–7 сутки — за 36–48 часов до макроскопического поникания побегов. В этот латентный период инструментальный индекс $NDVI_{\text{instr}}$ сохранял стабильное плато ($0.77–0.81$), подтверждая целостность пула хлорофилла в первые сутки устьичного стресса.
* **Уровень 4 (Агрономический эффект превентивного полива — Предварительный тренд):**  
  Предотвращение необратимой гибели растений подтверждено строго: К1 превосходит К5 ($p = 0.045, d = 1.08$), а К4 превосходит К3 ($p = 0.025, d = 1.17$). Различие между превентивным поливом по термоалерту (К4: $3.87$ г) и поливом по факту визуального увядания (К5: $2.85$ г) составило $+35.8\%$ суммарной биомассы, однако из-за высокой кассетной вариабельности ($CV = 50.0\%$) различие средних носит характер умеренного биологического тренда ($t = 1.18, p = 0.256$, размер эффекта Cohen's $d = 0.56$). Статистическое подтверждение эффекта на независимой выборке вынесено во Вторую волну.
* **Уровень 5 (Экономическая эффективность — Теоретический прогноз):**  
  Оценки предотвращения потерь урожая на уровне тепличного хозяйства носят расчетно-экстраполяционный характер (Assumed Model) и подлежат производственной валидации.

### Серия 2: Масштабирование на огурец (*Cucumis sativus*, сорт «Каскад», Волна 2)

Для преодоления ограничений кассетного размещения первой серии и проверки метода на широколистной культуре развернута Вторая волна исследований:
* **Биометрический дизайн (GRCBD по Доспехову, 1985):** Обобщенный рандомизированный полноблочный дизайн: 3 физических блока (поддона) $\times$ 3 группы (Контроль, Превенция, Реакция) $\times$ 2 повторности на блок = **18 независимых сосудов** ($7 \times 7 \times 8$ см) с систематической ротацией позиций внутри бокса для устранения пространственных градиентов освещенности и температуры.
* **Поисковая адаптогенная группа:** 2 изолированных сосуда (Э1, Э2) для оценки корень-ассоциированного прайминга 24-эпибрассинолидом («Эпин-Экстра»).
* **Лизиметрический контроль испарения почвы (стандарт FAO-56):** Сосуд $X0$ с чистым субстратом без растения позволяет гравиметрически разделить суммарную эвапотранспирацию ($ET$) на физическое испарение почвы ($E$) и чистую устьичную транспирацию растения ($T = ET - E$).
* **Дифференциальный критерий стресса:** Переход от абсолютного $\Delta T$ к нормализованному $\Delta\Delta T = \Delta T_{\text{опыт}} - \overline{\Delta T}_{\text{контроль}} \ge +0.6^\circ\text{C}$ относительно интактных растений контрольной группы в том же блоке.
* **Статус (на конец октября 2026 г.):** Посев 25.10.2026, 100% дружные всходы (20/20 сосудов). Дифференцированная стресс-фаза начинается в фазе 1-го настоящего листа. Подробные регламенты: [`docs/wave2/PROTOCOL_WAVE2_CUCUMBER.md`](docs/wave2/PROTOCOL_WAVE2_CUCUMBER.md).

## 5. Методологические допущения и ограничения исследования (Limitations)

Для соблюдения стандартов академической честности и объективной интерпретации результатов авторами сформулированы следующие границы применимости исследования:

1. **Биометрический статус выборки в первой серии (псевдорепликация по Hurlbert, 1984):**  
   В пилотной Серии 1 фактор орошения задавался на уровне кассеты целиком, что делает физическую кассету экспериментальной единицей ($N=1$), а отдельные ячейки C1–C9 — субвыборкой (*subsamples*). Различие в сохраненной биомассе между К4 и К5 ($+35.8\%$, $d = 0.56$, $p = 0.256$) строго трактуется как предварительный агрономический тренд. Преодоление этого ограничения (переход на независимые горшки и полный рандомизированный блочный план GRCBD с Two-Way ANOVA) является главной целью развернутой Второй серии.
2. **Аппаратное ограничение почвенной телеметрии (3 датчика в наличии):**  
   В аппаратном ресурсе установки имелось ровно 3 откалиброванных емкостных сенсора почвы (шина I2C, 4-канальный АЦП ADS1115), поэтому они были физически размещены в трех контрастных реперных когортах: К1 (Контроль), К2 (Осмос) и К3 (Терминальная засуха). В когортах превентивного и реактивного полива (К4 и К5) непрерывный мониторинг расхода влаги обеспечивался неинвазивным весовым методом (ежедневным взвешиванием кассет на аналитических весах), что дополнительно исключило механическое травмирование корневой зоны щупами при локальном поливе шприцем.
3. **Операционный характер базовой линии CWSI (Идсо, 1981):**  
   Уравнение водного стресса покрова ($\text{CWSI}_{\text{instr}}$) выведено на калибровочном Стенде №0 по трем контрастным микроклиматическим точкам помещения (ванная, подоконник, радиатор) с коэффициентом аппроксимации $R^2 = 0.985$. Полученная регрессия является операционной базовой линией, откалиброванной строго под конструктивную геометрию бокса и оптические свойства гороха «Альфа», и не претендует на статус фундаментальной биофизической константы для открытого поля.
4. **Инструментальный статус спектрального индекса $NDVI_{\text{instr}}$:**  
   Показатель $NDVI_{\text{instr}}$ представляет собой узкополосный аппаратно-зависимый индекс активного двухволнового зондирования (660 / 850 нм) бытовой NoIR-матрицей. Он оптимизирован для оценки внутрисерийной динамики оптической плотности в закрытом боксе и не подлежит прямому сопоставлению с данными спутниковых группировок или широкополосных полевых радиометров без специализированного переводного коэффициента.
5. **Видоспецифичность и границы биологической экстраполяции:**  
   Временной интервал опережения (36–48 ч между температурным алертом и потерей тургора) зарегистрирован на ювенильной стадии бобовой культуры (*Pisum sativum*) при температуре $21–24^\circ\text{C}$ и дефиците упругости пара $VPD = 1.0\dots 1.4$ кПа. Скорость развития водного дефицита у других культур (в частности, у широколистного огурца *Cucumis sativus* с иной архитектоникой побега и плотностью устьиц) имеет видоспецифичный характер и подлежит экспериментальному определению во Второй волне.
6. **Прогнозный характер экономической оценки (Assumed Model):**  
   Любые расчеты экономической эффективности, сроков окупаемости установки и снижения потерь урожая в теплицах носят сугубо теоретический модельный характер (сценарный прогноз). Фактический агроэкономический эффект требует валидации в натурных условиях промышленного тепличного комбината.

## 6. Быстрый старт и структура проекта

### Установка и запуск
```bash
# 1. Клонирование репозитория
git clone https://github.com/ezicvtumane/plant-stress-ndvi.git
cd plant-stress-ndvi

# 2. Создание виртуального окружения и установка зависимостей
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Запуск набора автоматических тестов (36 unit-тестов)
pytest tests/

# 4. Запуск операторской веб-станции (FastAPI)
python web_station.py
# Веб-панель доступна по адресу http://localhost:8000
```
