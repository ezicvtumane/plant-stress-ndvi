# 🌿 Медиа-архив научно-исследовательского комплекса

В данном каталоге систематизированы фото-, мультиспектральные и термографические материалы, полученные аппаратно-программным комплексом активной спектрофотометрии и термографии в ходе 11-дневного синхронного эксперимента по индикации водного и осмотического стресса.

## 🗄️ Разделение натурных замеров и технической калибровки

Для строгой воспроизводимости и чистоты научных результатов данные строго разделены:

1. **[Синхронная 11-дневная серия натурных замеров (Дни 1–11)](experiment_series_pea/README.md)**:
   * Содержит 110 чистовых инструментальных файлов (55 мультиспектральных карт NDVI + 55 калиброванных термограмм) для 55 натурных исследований когорт #1–5 за 8–18 октября 2026 г.
   * Включает натурные фотографии фенотипического статуса когорт, иллюстрирующие 48-часовой интервал между сигналом прибора и визуальным увяданием в Серии 1 (горох), гравиметрию на весах, исходы засухи и деструктивный сбор биомассы с верификацией корневой изоляции.
   * Полностью синхронизировано с базой данных `data/experiments/exp_1791463544/measurements.csv` и `data/measurements.csv`.
2. **Технические и пристрелочные снимки**:
   * Размещены в [`data/experiments/exp_1791463544/test_calibration_shots/`](../data/experiments/exp_1791463544/test_calibration_shots/).
   * Включают тестовые кадры юстировки оптического бокса, проверки ArUco-маркеров и калибровки радиометрического эталона.
3. **Фотоальбом сборки и биологии**:
   * Подробный иллюстрированный отчет с описанием всех этапов доступен в [`docs/PHOTO_ALBUM.md`](../docs/PHOTO_ALBUM.md).
4. **Материалы для видеомонтажа и презентаций**:
   * [`video_slide_5_cohorts_1080p.png`](video_slide_5_cohorts_1080p.png) — широкоформатный титр-коллаж ($1920 \times 1080$, 16:9) с визуализацией и экспресс-характеристиками всех 5 когорт.
   * [`video_clip_5_cohorts_3sec.mp4`](video_clip_5_cohorts_3sec.mp4) — готовый 3-секундный видеоклип 1080p 30fps с плавным фейдом для прямого добавления на таймлайн видеоролика.
   * Генератор видеоматериалов: [`scripts/generate_cohort_video_slide.py`](../scripts/generate_cohort_video_slide.py).
