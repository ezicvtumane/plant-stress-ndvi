## 1. Стратегическая трёхэтапная архитектура (TRL 3 → 4 → 5)

Исследование выстроено по строгой методологической модели уровней готовности технологий (TRL), разделяющей пилотную калибровку, полномасштабную биологическую валидацию и последующую инженерную автоматизацию:

```
┌───────────────────────────────────────┐       ┌───────────────────────────────────────┐       ┌───────────────────────────────────────┐
│        ЭТАП 1: ВОЛНА 1 (TRL 3)        │       │        ЭТАП 2: ВОЛНА 2 (TRL 4)        │       │        ЭТАП 3: ВОЛНА 3 (TRL 5)        │
│ • Культура: Pisum sativum («Альфа»)   │  ──>  │ • Культура: Cucumis sativus («Каскад»)│  ──>  │ • Инженерный моноблок TRL 5           │
│ • Обнаружение лага 36–48 ч            │       │ • Комплекс GRCBD (Доспехов, N=18)     │       │ • Встраиваемый USB-сенсор 256×192     │
│ • Декларация псевдорепликации         │       │ • Лизиметр X0 (чистое испарение)      │       │ • Полная энергоавтономия (Powerbank)  │
│ • Деструктивный срез биомассы         │       │ • Сателлит №20 (устьичные слепки)     │       │ • Экспресс-тест (N=6: 2К + 2П + 2Р)   │
│ • СТАТУС: ЗАВЕРШЕНА                   │       │ • СТАТУС: АКТИВНА СЕЙЧАС (BBCH 12)    │       │ • СТАТУС: ПЛАН РАЗВИТИЯ (ROADMAP)     │
└───────────────────────────────────────┘       └───────────────────────────────────────┘       └───────────────────────────────────────┘
```

## 2. Этап 1 (Волна 1, Горох «Альфа»): Пилотная калибровка (TRL 3, ЗАВЕРШЕНА)

* **Объект и объем выборки:** Горох посевной (*Pisum sativum L.*, сорт «Альфа», гликофит), 45 растений в 5 кассетах, 55 сессий замеров (ID #167–#281 в `data/measurements.csv`).
* **Ключевой феномен:** Впервые экспериментально зафиксирован временной интервал опережения порядка **36–48 часов** между первыми признаками устьичной окклюзии ($\Delta T = +1.2\dots+1.8\,^\circ\text{C}$) и видимой макроскопической потерей тургора побегов при неизменном оптическом пологе ($\text{NDVI}_{\text{instr}} = 0.715\dots0.784$).
* **Биометрический результат:** Группа К4 (Превенция) vs К5 (Реакция): $+35.8\%$ по сырой надземной массе на 11-й день, $p = 0.256$, Cohen’s $d = 0.56$ (умеренный биологический тренд); К4 vs К3 (Засуха): $p = 0.025$, $d = 1.17$ (достоверное предотвращение гибели биомассы).
* **Методологический статус (Hurlbert, 1984):** Кассетная псевдорепликация открыто задекларирована ($n_{\text{eff}} = 1$), независимая биологическая валидация выполнена разрушающим учетом 45 индивидуальных корневых систем.

## 3. Этап 2 (Волна 2, Огурец «Каскад»): Биометрический монолит GRCBD (TRL 4, АКТИВНА)

* **Культура и фенология:** Огурец посевной (*Cucumis sativus L.*, сорт «Каскад»). Посев 25.10.2026. Фаза BBCH 12 (раскрытие 1-го настоящего листа $\ge 3.5\text{ см}$) достигнута 05–06.11.2026.
* **Агротехнический регламент:** Выполнено окучивание (top-dressing) нейтральным торфом до семядолей для исключения вытягивания гипокотиля. Масса пустой тары стандартизирована до **5.0 г**, базовая целевая масса сосуда — **95.0 г** (100% стандартизированная полевая влагоемкость торфа). Установлены 2 фитолампы полного спектра и теплосветоотражающий экран.
* **Матрица распределения (20 сосудов в двух лотках):**
  1. **Основной дисперсионный комплекс GRCBD (18 независимых сосудов):**
     * 3 блока $\times$ 3 группы (**Контроль**, **Превенция**, **Реакция**) $\times$ 2 повторности на блок.
     * Систематическая циклическая ротация поддонов с разворотом на $180^\circ$ для компенсации краевых градиентов микроклимата.
     * Боковые ветки с экзогенными адаптогенами («Эпин») полностью исключены для сохранения строгой ортогональности и математической чистоты двухфакторного ANOVA ($df_E = 9$).
  2. **Контрольный лизиметр испарения (сосуд X0):**
     * Дефектный карликовый росток срезан под корень вровень с грунтом. Сосуд с идентичной структурой ризосферы и историей полива конвертирован в лизиметр $X0$ для ежедневного гравиметрического вычитания чистого физического испарения почвы $\Delta m_{\text{исп}}$ (поправка FAO-56).
  3. **Параллельный сателлитный донор микроскопии (сосуд №20, Sacrificial Satellite):**
     * Проходит режим дегидратации параллельно группе «Реакция». Служит для прижизненного снятия эпидермальных слепков устьиц на ключевых фазах засухи, полностью защищая листья 18 основных растений GRCBD от химических и механических микротравм лаком и скотчем. Одновременно выполняет роль страхового резерва на случай форс-мажора.
* **Регламент дифференцированного полива:**
  * **Контроль (К1–К6):** Ежедневный долив отстоянной водой строго до $100.0\text{ г}$.
  * **Превенция (П1–П6):** Полив возобновляется строго при подтверждении дифференциального критерия $\Delta\Delta T = \Delta T_{\text{опыт}} - \overline{\Delta T}_{\text{контроль}} \ge +0.6\,^\circ\text{C}$ на двух замерах подряд.
  * **Реакция (Р1–Р6):** Полив возобновляется строго при визуальном макроскопическом увядании (балл тургора 2 по 4-балльной шкале, поникание листа $>45^\circ$).
* **Конечная точка (Endpoint):** Одновременная деструктивная срезка и взвешивание сырой и абсолютно сухой биомассы всех 18 сосудов ровно через **48 часов после регидратации группы «Реакция»** для оценки необратимости продуктивных потерь.

## 4. Этап 3 (Волна 3): Перспективный план перехода на TRL 5 (Roadmap)

> [!NOTE]
> Данный раздел представляет собой проектную архитектуру модернизации и научно-технический план развития (Roadmap). Проведение этапа запланировано после завершения базовой биометрической серии Волны 2.

### 4.1. Аппаратная модернизация (Инженерный моноблок TRL 5)
1. **Интеграция радиометрического VOx-микроболометра $256 \times 192$ (Hti HT-203U):**
   * Монтаж стационарного модуля жестко в верхнюю панель измерительного бокса на едином оптическом риге рядом с камерой Sony IMX179 NoIR.
   * Прямое подключение по USB Type-C к Orange Pi 4 Pro с захватом некомпрессированного 16-битного радиометрического видеопотока (Linux V4L2 / UVC Y16, `2bdf:0102 HIK HikCamera`).
   * Аппаратная NUC-шторка исключает температурный дрейф нуля при нагреве электроники в замкнутом объеме бокса.
   * Полный отказ от внешнего ручного прибора UNI-T UTi120S и программного распознавания экрана через Tesseract OCR.
2. **Мультимодальный Image Fusion:**
   * Программное совмещение высокодетализированной маски листовой пластинки из 8MP NoIR-кадра с радиометрической матрицей $256 \times 192$ ($49\,152$ температурные точки).
   * Автоматическое исключение теплового фона почвы и расчет чистой температуры листа $T_{\text{leaf}}$ с субградусной погрешностью.
3. **Энергоавтономия и полевой форм-фактор:**
   * Питание станции от внешнего Powerbank через Type-C PD (потребление оптимизировано за счет импульсного стробирования светодиодов длительностью 200–300 мс).
   * Автономная точка доступа Wi-Fi `192.168.4.1` (SSID `PlantStation`) для управления комплексом и визуализации термограмм с любого смартфона или планшета без локальной сети.
4. **Интеграция замкнутого микро-фитотрона и аппаратной взаимной блокировки (Zero-Code Hardware Interlock):**
   * Монтаж компактного LED-модуля полного спектра (фитоленты 3–5 Вт) для обеспечения стабильного ФАР (фотосинтетически активной радиации) и фотопериода (16/8 ч) непосредственно внутри измерительного бокса.
   * **Аппаратная взаимоблокировка через нормально замкнутые (NC) контакты реле:** Последовательное включение контактов `COM1-NC1` и `COM2-NC2` в цепь питания ленты. В момент активации любого измерительного канала (Red 660 нм или NIR 850 нм) фитосвет мгновенно и аппаратно обесточивается без необходимости программной синхронизации или переписывания базового кода станции.
   * **Высококачественный фоновый RGB-таймлапс кинетики роста и нутаций:** В периоды естественного свечения фитоленты встроенная NoIR-камера фиксирует развитие вегетативной массы в видимом диапазоне в реальном времени (суточные циркадные движения листьев, скорость прироста площади листовой пластинки, тургорная динамика), формируя непрерывный демонстрационный видеоряд для защиты проекта.

### 4.2. Инженерно-динамический экспресс-тест (Мини-когорта N = 6)
* **Культура:** Огурец посевной (*Cucumis sativus L.*, сорт «Каскад»). Выбор обусловлен необходимостью соблюдения метрологического принципа единства измерений (нельзя одновременно менять измерительный сенсор и объект измерения). Срок доращивания 6 стаканчиков до BBCH 12 — 10–12 дней.
* **Матрица экспресс-теста (N = 6):**
  * 2 сосуда — **Контроль** (К1, К2)
  * 2 сосуда — **Превенция** (П1, П2)
  * 2 сосуда — **Реакция** (Р1, Р2)
  * Наличие внутренней повторности ($n=2$) позволяет отображать на графиках доверительные интервалы и коридоры ошибок ($\pm\text{SE}$).
* **Регламент измерений:** 3-суточный динамический мониторинг в комфортном режиме уикенда (2–3 замера в сутки по 3.5 минуты: утро, день, вечер).
* **Что подтверждается:**
  1. Синхронное нарастание $\Delta\Delta T \ge +0.6\,^\circ\text{C}$ при закрытии устьиц.
  2. Превентивный полив $\to$ **динамика восстановления транспирационного охлаждения листа за 2–4 часа** непосредственно на встроенном графике новой камеры.
  3. Сохранение запаздывания отклика у группы визуального увядания.
* **Метрологическая кросс-калибровка приборов (Бланд–Альтман):**
  * Параллельное снятие серии контрольных термограмм эталоном UNI-T UTi120S и новым модулем HT-203U на контрастных температурных мишенях (сытый лист, подвядший лист, калибровочные пластины $15\dots 30\,^\circ\text{C}$).
  * Построение графика сходимости Бланда–Альтмана ($R^2 \ge 0.98$, 40–50 парных точек) для подтверждения метрологической преемственности рядов данных между TRL 4 и TRL 5 по ГОСТ Р ИСО 5725 / CLSI EP09.
