# Рабочая документация эксперимента и аппаратного комплекса

В данном каталоге собраны оперативные рабочие материалы, протоколы натурных измерений, калибровочные архивы и инженерные схемы действующего исследовательского комплекса:
**«Оптико-электронный комплекс активной двухволновой спектрофотометрии и термографии для ранней индикации водного и осмотического стресса растений»**.

> **Автор**: Ковалева Алиса Ивановна, 10 класс, ГБОУ СОШ №282 Кировского района Санкт-Петербурга  
> **Руководитель**: Ковалев Иван Викторович  
> **Конкурс**: Всероссийский конкурс научно-технологических проектов «Большие вызовы» (ОЦ «Сириус»)

## Рубрикатор актуальных материалов

### 1. Экспериментальные протоколы и логи
* [**`DATA_CHANGELOG.md`**](DATA_CHANGELOG.md) — Официальный журнал изменений данных и верификации измерений (*append-only*).
* [**`PHOTO_ALBUM.md`**](PHOTO_ALBUM.md) — Иллюстрированный фотожурнал натурных замеров серии 8–15 октября (карты NDVI, термограммы UTi120S, микроскопия устьиц).
* [**`ЛАБОРАТОРНЫЙ_ЖУРНАЛ_ИССЛЕДОВАНИЯ.md`**](ЛАБОРАТОРНЫЙ_ЖУРНАЛ_ИССЛЕДОВАНИЯ.md) — Синхронный лабораторный журнал замеров с динамикой массы, температуры, влажности и индекса NDVI.
* [**`БЛАНК_ПРОТОКОЛА_ИЗМЕРЕНИЙ.md`**](БЛАНК_ПРОТОКОЛА_ИЗМЕРЕНИЙ.md) — Рабочий бланк лабораторного протокола для оператора при ручной фиксации данных.
* [**`STATISTICAL_ANALYSIS_SERIES1.md`**](STATISTICAL_ANALYSIS_SERIES1.md) — **Биометрический отчёт пилотной серии (горох)**: проверка нормальности (Шапиро–Уилк), t-критерии Уэлча, Манн–Уитни, размер эффекта Cohen's d, корреляции телеметрии.
* [**`DEFENSE_QA_GUIDE.md`**](DEFENSE_QA_GUIDE.md) — **Шпаргалка для очной защиты**: ответы на 16 ключевых вопросов жюри и рецензента (псевдорепликация и переход к GRCBD, $k_{\text{bal}}$, OCR, вариабельность К4, личный вклад автора).
* [**`wave2/`**](wave2/) — **Вторая экспериментальная серия (Огурец «Каскад»)**: рандомизированный блочный дизайн GRCBD по Доспехову ($N = 18$ плюс лизиметр $X0$ и пилот $E1, E2$), протокол опыта [`PROTOCOL_WAVE2_CUCUMBER.md`](wave2/PROTOCOL_WAVE2_CUCUMBER.md), шаблоны журналов и результаты дисперсионного анализа ANOVA.

### 2. Калибровочные данные и фотофиксация
* [**`calibration/`**](calibration/) — Фотоархив и термограммы натурной эмпирической калибровки опорных уровней CWSI по Идсо (контрастные среды: ванная комната, батарея, подоконник, вазелиновый барьер). Подробный протокол см. в корневом файле [`CALIBRATION.md`](../CALIBRATION.md).
* [**`images/`**](images/) — Натурные фотографии сборки фотометрического бокса, схемотехники, фторопластового эталона PTFE и микроскопии устьичных отпечатков по Молотилову.

### 3. Инженерная документация и шаблоны
* [**`opi4pro_pinout.png`**](opi4pro_pinout.png) — Принципиальная схема аппаратной распиновки контактов микрокомпьютера Orange Pi 4 Pro (линии I2C, ADS1115, SHT30, силовые ключи реле).
* [**`aruco_markers_sheet.pdf`**](aruco_markers_sheet.pdf) ([`.html`](aruco_markers_sheet.html)) — Векторный лист фидуциальных меток ArUco (словарь `DICT_4X4_50`) для автоматической калибровки оптического поля и детекции кассет.
