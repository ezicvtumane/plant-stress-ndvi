# 🌿 Медиа-архив научно-исследовательского комплекса

В данном каталоге систематизированы фото-, мультиспектральные и термографические материалы, полученные аппаратно-программным комплексом активной спектрофотометрии и термографии в ходе 7-дневного синхронного эксперимента по индикации водного и осмотического стресса.

## 🗄️ Разделение натурных замеров и технической калибровки

Для строгой воспроизводимости и чистоты научных результатов данные строго разделены:

1. **[Синхронная 7-дневная серия натурных замеров (Дни 1–7)](experiment_series_pea/README.md)**:
   * Содержит 70 чистовых инструментальных файлов (35 мультиспектральных карт NDVI + 35 калиброванных термограмм) для 35 натурных исследований когорт #1–5 за 8–14 октября 2026 г.
   * Включает натурные фотографии фенотипического статуса когорт, подтверждающие 48-часовое окно упреждения между сигналом прибора и визуальным увяданием.
   * Полностью синхронизировано с базой данных `data/experiments/exp_1791463544/measurements.csv`.
2. **Технические и пристрелочные снимки**:
   * Размещены в [`data/experiments/exp_1791463544/test_calibration_shots/`](../data/experiments/exp_1791463544/test_calibration_shots/).
   * Включают тестовые кадры юстировки оптического бокса, проверки ArUco-маркеров и калибровки радиометрического эталона.
3. **Фотоальбом сборки и биологии**:
   * Подробный иллюстрированный отчет с описанием всех этапов доступен в [`docs/PHOTO_ALBUM.md`](../docs/PHOTO_ALBUM.md).
