# 🎨 Статические ресурсы веб-станции PlantStation

В данном каталоге размещены графические ресурсы веб-интерфейса станции, калибровочные маркеры и печатные материалы для оператора:

---

## 📁 Структура каталога

* [`logos/`](logos/) — Графические элементы интерфейса оператора (логотип трека «Агропромышленные и биотехнологии», эмблема конкурса «Большие вызовы» и фон веб-панели).
* [`aruco/`](aruco/) — Калибровочные маркеры ArUco (словарь `DICT_4X4_50`, ID 1–6) для автоматического оптического позиционирования кассет и эталона.
* [`aruco_markers_sheet.pdf`](aruco_markers_sheet.pdf) ([`.html`](aruco_markers_sheet.html)) — Утвержденный печатный лист маркеров формата А4 для наклейки на рассадные кассеты 5 экспериментальных когорт (доступен для скачивания оператором прямо из веб-интерфейса).
