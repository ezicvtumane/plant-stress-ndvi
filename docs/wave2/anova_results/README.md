# Валидационный модуль биостатистики Волны 2 (Mock Pipeline)

> [!WARNING]
> **МЕТРОЛОГИЧЕСКИЙ СТАТУС ДАННОГО КАТАЛОГА: СИНТЕТИЧЕСКИЙ ТЕСТОВЫЙ ШАБЛОН (MOCK)**  
> Файлы в этом каталоге (`FINAL_HARVEST_TEMPLATE_20PLANTS.csv`, `DOSPEKHOV_ANOVA_REPORT.txt`, `DOSPEKHOV_ANOVA_TUKEY_PLOTS.png`) представляют собой **синтетический валидационный пайплайн**.  
> Они сгенерированы скриптом [`scripts/run_dospekhov_anova.py`](../../../scripts/run_dospekhov_anova.py) для сквозного тестирования математического аппарата двухфакторного дисперсионного анализа (GRCBD по Доспехову) и апостериорного критерия Тьюки (HSD) до физического завершения вегетационного периода.

---

### Календарный статус эксперимента «Волна 2» (Огурец «Каскад»)
* **Дата посева:** 25 октября 2026 г.
* **Дата всходов:** 28 октября 2026 г. (дружные всходы в 19 биологических сосудах: 18 основных `3×3×2` + сателлит `C20`, плюс холостой лизиметр $X0$).
* **Текущая фаза:** семядольные листья (возраст 3–4 суток), дифференцированный стресс запускается в фазе 1-го настоящего листа.
* **Физическая уборка урожая:** Деструктивный срез биомассы ($FW$, $DW$, $WC$, $WUE$) будет проведен по завершении стресс-периода (~ноябрь 2026 г.). После сбора натурные данные заменят тестовый шаблон `FINAL_HARVEST_TEMPLATE_20PLANTS.csv`.

---

### Состав валидационного набора
1. `FINAL_HARVEST_TEMPLATE_20PLANTS.csv` — структура и шаблон табличного массива для внесения натурных весов 19 биологических сосудов (`18 GRCBD + C20`, всего 20 позиций вместе с $X0$; содержит синтетические тестовые веса).
2. `DOSPEKHOV_ANOVA_REPORT.txt` — эталонный формат протокола двухфакторного дисперсионного анализа (факторы: Полив, Блоки/Поддоны, Взаимодействие $A \times B$, остаточная ошибка $df=9$, критерий $F$, `Tukey HSD₀₅`, `НСР₀₅`).
3. `DOSPEKHOV_ANOVA_TUKEY_PLOTS.png` — типовая графическая 4-панельная визуализация 300 DPI (по стандартам ВАК и конкурса «Большие вызовы») с разнесением буквенных групп различий (a, b, c) и ориентиром сателлита `C20` ($n=1$, вне матрицы ANOVA).
