# Электрическая схема и коммутация (Wiring & Pinout)

## 1. Архитектура подключения

```text
               +-------------------------------------------------+
               |             5V DC / 3A Power Supply            |
               +-----------------------+-------------------------+
                                       |
                   +-------------------+-------------------+
                   | 5V                                    | 5V
                   v                                       v
         +-------------------+                   +-------------------+
         |   Mini360 (#1)    |                   |   Mini360 (#2)    |
         | Out: 3.30V (850nm)|                   | Out: 2.45V (660nm)|
         |                   |                   | Cur: 550 mA       |
         +---------+---------+                   +---------+---------+
                   | V+                                    | V+
                   |                                       |
                   v                                       v
           [Relay Channel 1]                       [Relay Channel 2]
               (NO1 / COM1)                            (NO2 / COM2)
                   |                                       |
                   v                                       v
         [850 nm NIR LED/Mod]                    [660 nm Deep Red LED]
         (with common GND)                       (on heatsink + GND)
                   ^                                       ^
                   |                                       |
                   +------------- Control Lines -----------+
                                  (IN1, IN2)
                                       |
                                       v
                             +-------------------+
                             |     Orange Pi     |
                             |  GPIO Control &   |
                             |  Armbian System   |
                             +----+---------+----+
                                  |         |
                          I2C Bus |         | USB
                      (SDA / SCL) |         |
                                  v         v
                         +-------------+   +-------------------+
                         |   ADS1115   |   |   USB NoIR Cam    |
                         |  (Addr 0x48)|   |   (/dev/video0)   |
                         +----+---+----+   +-------------------+
                              |   |
                   Analog In  |   | Analog In
                         (A0) |   | (A1)
                              v   v
                [Soil Moisture Sensors v1.2]
```

## 2. Таблица распиновки (Pinout Table)

### АЦП ADS1115 -> Orange Pi (Шина I2C-1)
| Пин ADS1115 | Назначение | Пин Orange Pi (40-pin header) | Описание |
|:---:|:---:|:---:|:---|
| **VDD** | Питание | 3.3V (Pin 1) | Стабильное логическое питание |
| **GND** | Общий провод | GND (Pin 6 или 9) | Общая земля |
| **SCL** | Тактирование I2C | I2C1_SCL (Pin 5) | Тактовая линия шины I2C |
| **SDA** | Данные I2C | I2C1_SDA (Pin 3) | Линия данных шины I2C |
| **ADDR** | Выбор адреса | GND | Привязка к GND задает I2C адрес `0x48` |
| **A0** | Аналоговый вход 0 | Выход сенсора влажности №1 | Реперный образец |
| **A1** | Аналоговый вход 1 | Выход сенсора влажности №2 | Исследуемый образец |

### Модуль 2-канального реле -> Orange Pi
| Пин модуля реле | Назначение | Пин Orange Pi (40-pin header) | Описание |
|:---:|:---:|:---:|:---|
| **VCC** | Питание катушек | 5V (Pin 2 или Pin 4) | Питание опторазвязки и реле (+5В) |
| **GND** | Общий провод | GND (Pin 6 или 9) | Общая земля системы |
| **IN1** | Управление каналом 1 | Pin 7 (PL4, gpiochip1 line 4) | Управление стробом 850 нм NIR |
| **IN2** | Управление каналом 2 | Pin 10 (PL7, gpiochip1 line 7) | Управление стробом 660 нм Deep Red |

### Сенсоры емкостной влажности v1.2 -> ADS1115
| Пин сенсора v1.2 | Подключение к ADS1115 / OPi | Описание |
|:---:|:---:|:---|
| **VCC** | 3.3V | Питание генератора емкостного датчика |
| **GND** | GND | Общий провод |
| **AOUT** | A0 / A1 | Аналоговое напряжение (1.30 В ... 2.75 В) |
